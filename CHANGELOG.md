# Changelog

All notable changes to LEXGUARD. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow `extension/manifest.json`.

## [0.6.0] - 2026-11-19
### Added
- **Ask LEXGUARD:** an offline chatbot in the side panel, checker page and web app. It answers from the current report, the rules and a 30-term glossary; quotes sentences and links to clauses; uses no AI model and uploads nothing.
- `eval/chat_test.js` (48 tests, including HTML-injection and clause-link checks).
- Security, release-readiness and compatibility audit reports in `docs/audits/`.
- `docs/ARCHITECTURE.md`, `docs/RULES.md` (generated by `tools/make_rules_doc.py`), `CONTRIBUTING.md`, this changelog, and issue and pull-request templates.
### Changed
- The project moved into the `LexGuard` repository, replacing an earlier React/Gemini prototype (still in the git history).
- README rewritten to match the current code: standalone extension, rule-based (no AI model), Chrome 116+, known limits.

## [0.5.1] - 2026-10-29
### Added
- Demo kit (`demo/`): risky and fair offer letters, freelance quotation and concert ticket terms as `.txt` and `.pdf`, a demo signup page, `HOW_TO_DEMO.txt`, and a 90-second demo video.
- A fair offer letter sample (scores 2/100) to show the Defender at work.
### Fixed
- "Personal projects … remain yours" is no longer flagged as an ownership risk.

## [0.5.0] - 2026-10-29
### Added
- "Who does it affect?" check in the Defender: the reader's own rights and the company's promises to the reader are removed and listed under **Not a risk for you**; rules that bind both sides are lowered.
### Changed
- UNFAIR-ToS test: precision 54.2% → 56.4%, fair sentences marked HIGH 3.6% → 3.0%, recall unchanged at 74.4%.

## [0.4.0] - 2026-10-29
### Added
- "What is this?" overview (purpose, company, reading time, topics in simple words), the "How LEXGUARD checked this" agent steps, and a score breakdown table.
- Light/dark switch.
### Changed
- The score counts each kind of risk once (HIGH 15, MEDIUM 5, LOW 1). Long terms pages no longer always score 99–100.
### Fixed
- Agent steps in the report wrapped one word per line.

## [0.3.0] - 2026-10-29
### Added
- Google four-colour theme and scroll animations, which respect reduced-motion settings.

## [0.2.1] - 2026-10-29
### Fixed
- "LEXGUARD can't read this tab" on normal websites: page access is now requested at the moment of the click.

## [0.2.0] - 2026-10-29
### Added
- Standalone extension: the engine runs in the browser (`extension/engine.js`), with a checker page for paste and `.txt`/`.pdf` upload (pdf.js), and a parity test against the Python engine.
### Changed
- Report shows a plain summary first, with details folded away.

## [0.1.0] - 2026-10-29
### Added
- Four-agent rule engine (Extractor, Risk Finder, Defender, Judge) with an India rule pack, a local web app, and the first Chrome extension.
- Synthetic benchmark and evaluation on LexGLUE UNFAIR-ToS and CUAD.
- Recall improvements: 4 new rules, wider patterns, held-out CUAD evaluation.
