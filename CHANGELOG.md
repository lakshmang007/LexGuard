# Changelog

All notable changes to LEXGUARD. Format: [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). Versions follow `extension/manifest.json`.

## [Unreleased]
### Changed
- Every risk card now shows the document's exact sentence next to the explanation (it was hidden under "See details").
### Added
- `docs/HOW_IT_WORKS.md`: how a PDF is read, the rules used instead of an AI prompt (and what the first Gemini version sent), and how the score is decided, with a worked example.

## [0.7.0] - 2026-11-23
### Added
- Language check in both engines (`engine/language.py`, `detectLanguage` in `extension/engine.js`). Documents that are mostly not in English (Hindi, Kannada, Chinese and so on) now get an "English documents only" notice instead of a false LOW score, in the report, side panel, checker, web app and chat.
- `tools/run_all_tests.py`: one command for the sync, a copies check, benchmark, parity, chat and server tests.
- GitHub Actions workflow (`.github/workflows/test.yml`): Ubuntu and Windows, Python 3.9 and 3.13, Node 20.
- `eval/server_test.py` (18 checks) and `requirements.txt` (optional `pypdf>=6.0`).
- A 60-second install video (`demo/LEXGUARD_Install_Video.mp4`) and an animated preview at the top of the README (`docs/images/demo-preview.gif`).
- A new 77-second demo video of 0.7.0 (`demo/LEXGUARD_Demo_Video.mp4`), with the current repository link.
- MIT licence, and `tools/make_release.py`, which builds `dist/LEXGUARD-<version>.zip` for GitHub releases.
- Benchmark target "Non-English documents refused"; 3 language cases in the parity check; 17 more chat tests (65 in all).
- Keyboard: Enter or Space on a risk card jumps to its sentence; cards have `role="button"` and a spoken label. Visible focus outline on cards.
### Changed
- In-page highlighting builds the page index once per check instead of once per flag: about 15 ms instead of 850 ms on a 30,000-word terms page, and about 0.1 s instead of 41 s on a page six times that size.
- The chat's intent checks are an ordered table; questions are capped at 300 characters. Answers are unchanged (compared on more than 8,000 questions).
- The extension requires Chrome 116 or newer (`minimum_chrome_version`).
- Light-theme medium-risk text is darker (contrast 5.6:1, was 4.3:1).
- `eval.public_datasets` writes `eval/results_public.*` only for the held-out test run.
### Fixed
- Local server: path tricks (`..`, UNC and device paths, drive letters) no longer reach files outside each route's folder; wildcard CORS removed; requests for other Host names get 403; bad or negative `Content-Length` gets 400 instead of hanging; bodies over 10 MB get 413; errors no longer leak details; security headers and a Content-Security-Policy are set; `/health` reports the real version.
- pdf.js runs with `isEvalSupported: false` (CVE-2024-4367).
- The side panel's terms-link list ignores `javascript:` and other non-web links.
- The score breakdown no longer scrolls sideways in a 320 px side panel.
- Highlighting stayed aligned after a Turkish "İ" on the page.
- Document text can no longer plant fake clause links or bold text in chat answers.

## [0.6.0] - 2026-11-19
### Added
- **Ask LEXGUARD:** an offline chatbot in the side panel, checker page and web app. It answers from the current report, the rules and a 30-term glossary; quotes sentences and links to clauses; uses no AI model and uploads nothing.
- `eval/chat_test.js` (48 tests, including HTML-injection and clause-link checks).
- Security, release-readiness and compatibility audit reports in `docs/audits/`.
- `docs/ARCHITECTURE.md`, `docs/RULES.md` (generated by `tools/make_rules_doc.py`), `CONTRIBUTING.md`, this changelog, and issue and pull-request templates.
### Changed
- The project moved into the `LexGuard` repository, replacing an earlier React/Gemini prototype (still in the git history).
- README rewritten to match the current code: standalone extension, rule-based (no AI model), Chrome 116+, known limits.

## [0.5.1] - 2026-10-29
### Added
- Demo kit (`demo/`): risky and fair offer letters, freelance quotation and concert ticket terms as `.txt` and `.pdf`, a demo signup page, `HOW_TO_DEMO.txt`, and a 90-second demo video.
- A fair offer letter sample (scores 2/100) to show the Defender at work.
### Fixed
- "Personal projects … remain yours" is no longer flagged as an ownership risk.

## [0.5.0] - 2026-10-29
### Added
- "Who does it affect?" check in the Defender: the reader's own rights and the company's promises to the reader are removed and listed under **Not a risk for you**; rules that bind both sides are lowered.
### Changed
- UNFAIR-ToS test: precision 54.2% → 56.4%, fair sentences marked HIGH 3.6% → 3.0%, recall unchanged at 74.4%.

## [0.4.0] - 2026-10-29
### Added
- "What is this?" overview (purpose, company, reading time, topics in simple words), the "How LEXGUARD checked this" agent steps, and a score breakdown table.
- Light/dark switch.
### Changed
- The score counts each kind of risk once (HIGH 15, MEDIUM 5, LOW 1). Long terms pages no longer always score 99–100.
### Fixed
- Agent steps in the report wrapped one word per line.

## [0.3.0] - 2026-10-29
### Added
- Google four-colour theme and scroll animations, which respect reduced-motion settings.

## [0.2.1] - 2026-10-29
### Fixed
- "LEXGUARD can't read this tab" on normal websites: page access is now requested at the moment of the click.

## [0.2.0] - 2026-10-29
### Added
- Standalone extension: the engine runs in the browser (`extension/engine.js`), with a checker page for paste and `.txt`/`.pdf` upload (pdf.js), and a parity test against the Python engine.
### Changed
- Report shows a plain summary first, with details folded away.

## [0.1.0] - 2026-10-29
### Added
- Four-agent rule engine (Extractor, Risk Finder, Defender, Judge) with an India rule pack, a local web app, and the first Chrome extension.
- Synthetic benchmark and evaluation on LexGLUE UNFAIR-ToS and CUAD.
- Recall improvements: 4 new rules, wider patterns, held-out CUAD evaluation.
